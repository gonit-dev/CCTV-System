📺 OBS Studio Integration

How to add this stream to OBS Studio:

  1. Open OBS Studio
  2. Click + in Sources panel → Media Source
  3. Create new source → give it a name
  4. Paste URL into "Input" field
  5. Check "Network Buffering" option
  6. Uncheck "Local File" option
  7. Click OK to add the source
